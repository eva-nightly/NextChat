## Identifiers

Parts of this product carry a permanent identifier in a comment: `<path-without-extension>::<Name>`. An agent
asked to change one experience (a button, the sheet it is in, the handler and prompt behind it) finds every
place it is made by searching the code for its ids, which move with the code when files move.

- 88 components, e.g. `// @uxid app/components/artifacts::Artifacts`
- 387 interactive elements, inside their opening tag, e.g. `<button /* @uxid app/components/artifacts::Artifacts.htmlpreview */ ...>`
- 16 endpoint handlers and functions that call a model, e.g. `// @uxid app/api/artifacts/route::handle`
- 2 instructions sent to a model, e.g. `// @uxid app/constant::DEFAULT_SYSTEM_TEMPLATE`

Every id, by kind: .eval/identifiers.md. The component inventory: .eval/design-system/components.md. Never edit, remove or copy an
id: they are additive and permanent, and a new part gets its own on Eva's next scan.
