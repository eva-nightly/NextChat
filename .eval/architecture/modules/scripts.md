# Module: scripts [AI]

A utility script that fetches, filters, and bundles community ChatGPT/LLM prompt templates across Simplified Chinese, Traditional Chinese, and English into a local static asset (public/prompts.json).

## Key files
- `scripts/fetch-prompts.mjs`: Fetches remote prompt datasets, filters out unwanted keywords, and saves the consolidated prompt list to public/prompts.json
