# Glossary

_Terms this company uses in a specific way, as their own material defines them._

## BASE_URL

The setting used to point the app at an OpenAI-compatible endpoint instead of a user-supplied API key.

> "Users bring their own API key, or point the app at an OpenAI-compatible endpoint through BASE_URL."
>
> — `about-nextchat.md`


## Conversation summary

A summary of a long chat that keeps it within the model's context window.

> "Conversation summaries that keep long chats within the context window."
>
> — `about-nextchat.md`


## Mask

A prompt preset for a role or task.

> "Saved conversations and "masks" (prompt presets for a role or task)."
>
> — `about-nextchat.md`
