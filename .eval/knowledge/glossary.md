## Good answer

An answer that is accurate, helpful, on-topic, follows the conversation context and the selected model/system prompt, and fails gracefully on errors.

> "A good answer is accurate, helpful, on-topic, follows the conversation context and the selected model/system prompt, and fails gracefully on errors."
>
> — `About_the_organisation.md`


## Mask

A system prompt that users can set for a chat.

> "Users can pick a model and set a system prompt (masks)."
>
> — `about.md`
