# The company

NextChat is a lightweight, self-hostable chat interface for large language models that relays user messages to an OpenAI-compatible model via OpenRouter and streams back answers.

> "It is a chat assistant: it relays the user's messages to an OpenAI-compatible model (via OpenRouter) and streams back answers."
